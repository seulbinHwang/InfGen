최종 통합 검사:

```bash
OMP_NUM_THREADS=2 .venv/bin/python scripts/verify_reproduction.py \
  --workdir output/verification-complete
```

이 명령은 각 단계를 별도 프로세스로 실행합니다. `report.json`에 6개 단계
`train`, `resume`, `rollout_80`, `rollout_300`, `repeat_80`, `future_invariance`의
종료 코드와 결과를 저장합니다. `.npz`는 `allow_pickle=False`로 확인합니다.
기존 결과를 덮어쓰지 않으므로 재실행하려면 빈 디렉터리를 선택하십시오.

최종 검증 로그·합성 체크포인트는 로컬 `output/verification-complete/`에
남기고 Git에는 포함하지 않았습니다. 합성 모델은 코드 검사용이며 실사용
학습 모델이나 논문 수치의 근거가 아닙니다.

## 검증 환경

- macOS 26.6, Apple Silicon arm64, **CPU 실행**.
- Python 3.10.17, PyTorch 2.5.1, PyTorch Lightning 2.4.0.
- torch-geometric 2.6.1, torch-cluster 1.6.3, torch-scatter 2.1.2.
- 나머지 실제 설치 버전: [runtime-macos.lock.txt](runtime-macos.lock.txt).
- PyTorch 확장 모듈은 현재 Mac의 SDK를 지정하여 소스 빌드했습니다.
- 논문 설정을 그대로 쓰되 검증 실행은 devices=1·합성 데이터·짧은 step 수로 제한했습니다.
